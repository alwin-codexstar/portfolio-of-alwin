## 💻 Running the Portfolio Locally

Clone the repository:

```bash
git clone https://github.com/alwin-codexstar/alwin-portfolio.git
```

Open the project folder:

```bash
cd alwin-portfolio
```

Then open `index.html` in your browser.

For the best experience during development, you can also use a local development server such as VS Code Live Server.
